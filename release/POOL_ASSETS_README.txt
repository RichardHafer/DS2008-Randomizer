Dead Space 2008 Randomizer - Pool Assets

This package contains the enemy pool archives, character copies and Enhanced
Exploder assets. Its version is independent of the plugin version and is listed
in the ZIP filename and ds1_randomizer_assets/RandomizerPoolAssets.json.

INSTALL

Close the game. Extract this ZIP into the folder containing Dead Space.exe,
keeping the ds1_randomizer_assets folder. Install the Plugin ZIP there as well.
The pool package alone does not load the mod.

UPDATES

Both packages are attached to each GitHub release. Only download the pool again
when the plugin release asks for a different pool version. Reuse an installed
pool when its version matches the one required by the plugin release.

Pool Assets 1.0.0 contains the same archives as the combined Randomizer 1.0.3
and 1.0.4 packages. Users with either complete package already installed can
keep those assets and download only the new Plugin ZIP.

The plugin package declares its required pool version in
DeadSpace2008Randomizer_package.json. Neither package downloads updates itself.
Console DLC assets are distributed by the separate Console DLC add-on.
